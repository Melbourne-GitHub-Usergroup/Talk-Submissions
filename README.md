# Talk Submissions for the Melbourne GitHub Usergroup

Welcome everyone 👋.

In the style of being a GitHub usergroup we thought it would be great to use GitHub to help us with managing submissions for talks.

If you would like to speak at the Melbourne Usergroup please do the following:
* fork this repo
* add in a text or markdown file with the filename: `[YOUR_NAME]_[TALK_TITLE].md`
* Raise a pull request against this repo.

The plan is that we can create a backlog of talks and work through these so everyone gets a chance to speak.

If you have any questions please raise an issue or feel free to email one of the organsers:

- Dylan: dylan.v.mccarthy@gmail.com
- Mish: mish@mishmanners.com

We will do our best to announce the selected talks two weeks prior to the event date. We may also try to align meetups with dates people are available. Please remember to put your PRs on notifications or regularly check GitHub, as we'll be commenting on PRs when we're looking at selecting your talk.
